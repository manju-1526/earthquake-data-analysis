🌍 Earthquake Data Analysis Dashboard

An interactive Earthquake Data Analysis Dashboard built using Python, MySQL, Aiven Cloud, and Streamlit.

📌 Project Overview

This project collects and analyzes earthquake data and presents the results through an interactive dashboard.

The dashboard helps users explore earthquake activity using:

Earthquake magnitude
Location
Year
Depth
Tsunami events
Monthly and yearly trends
🛠️ Technologies Used
Python
Pandas
MySQL
Aiven Cloud
SQLAlchemy
Streamlit
GitHub
📊 Dashboard Features
🌍 Total earthquake count
📈 Highest magnitude
📊 Average magnitude
🌊 Tsunami event count
📅 Year-wise earthquake analysis
📍 Location-based filtering
📉 Magnitude distribution
🌐 World map visualization
📊 Monthly earthquake trend
🔎 Magnitude vs depth analysis
📥 CSV data download
🗄️ Data Storage

The earthquake data is stored in MySQL and connected to Aiven Cloud MySQL.

The Streamlit dashboard retrieves the latest 5 years of earthquake data for analysis and visualization.

🚀 Live Dashboard

The project dashboard is deployed using Streamlit Community Cloud.

👉 [Open Live Earthquake Dashboard](https://earthquake-data-dashboard.streamlit.app/)
